What to know before using real data

SQLite Sprig copies actual data. It does not mask or anonymize it. The alpha supports ordinary SQLite tables with declared foreign keys; virtual tables and custom extensions are outside its scope. Source access is read-only and an existing output is never replaced. This page shows precomputed, downloadable results from authored data; the extraction runs through the CLI.
