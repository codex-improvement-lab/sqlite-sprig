# SQLite Sprig

This is an independent Git repository in Codex Improvement Lab. Work only in this repository for Git, package, tests and release operations.

The narrow promise: select a branch of an ordinary local SQLite database, add the parents it needs, and create a usable SQLite file with ordinary schema retained. Keep a read-only source snapshot, declared-FK selection, bounded work and no-overwrite output publication. It is not a data masker, failure minimizer or server-database tool. Never silently widen the root selection to every sibling of a parent added for integrity.

Use Python 3.11+ and its standard library at runtime. SQLite 3.37+ is required. Keep the CLI JSON contract and importable API small. Preserve authored examples and meaningful behavior tests for constraints, schema, selection, source preservation and output publication.

Preview, local tests, hosted CI, internal agent evaluations and real external adoption are separate evidence levels. Do not claim measured time savings from one task or process timing. Document limitations and successful existing-tool alternatives.

Follow ../docs/LAB_VISUAL_DIRECTION_2026-10-04.md for demos and promotion. Inspect actual layouts at desktop and narrow widths and include a reduced-motion presentation. Promote the real extraction result, not a fabricated performance claim.

Publishing is authorized by the Lab owner's standing instructions. Keep releases prerelease until their maturity justifies otherwise. No secrets, user databases, private conversation exports or Lab internal paths in public artifacts.
